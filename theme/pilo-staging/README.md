# Pilo – STAGING (theme 210675073373)

Working copies of the files edited through the Admin API for the current
staging theme. Only files that have been changed here are kept, not the whole
theme — pull a fresh copy from the theme before editing one, because the theme
editor writes to these files too.

`theme/staging/` and `theme/live/` in this repo belong to the older
`azure-theme` pair, which no longer exists on the store.
